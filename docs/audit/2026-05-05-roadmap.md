# Roadmapa Ulepszen (Admin-First)

## Faza A (1-2 tygodnie) - Stabilnosc i Bezpieczenstwo
- Wdrozenie JWT auth + refresh token flow.
- Wymuszenie RBAC na endpointach admina i middleware/matcher na trasach `/admin`.
- Rate limiting (`/auth`, `/quotes`, `/tracking`) i CORS per environment.
- Standaryzacja bledow API (`code`, `message`, `details`).
- Szacunek: 6-9 dni roboczych.

## Faza B (2-4 tygodnie) - Funkcjonalny Admin CRUD
- Orders admin: lista, filtrowanie, zmiana statusu, notatki.
- Leads admin: przypisanie handlowca, statusy, historia kontaktu.
- Users admin: role, aktywacja/dezaktywacja, reset hasla administracyjny.
- CMS admin: zapis do DB + publikacja + walidacja.
- Szacunek: 10-16 dni roboczych.

## Faza C (1-2 tygodnie) - Monitoring i Operacyjnosc
- `GET /health` + metryki aplikacyjne.
- Strukturalne logi JSON.
- Alerty na bledy integracji i timeouty.
- Audit log zmian admina (kto/co/kiedy/przed/po).
- Szacunek: 5-8 dni roboczych.

## Faza D (2-3 tygodnie) - Wydajnosc i Skala
- Indeksy DB dla tras krytycznych (orders/leads/tracking).
- Cache strategia dla quote/tracking i metadata.
- Benchmark endpointow + k6 baseline.
- Optymalizacja frontend CWV (LCP/INP/CLS) na podstawie telemetry.
- Szacunek: 8-12 dni roboczych.

## Faza E (1-2 tygodnie) - Zaawansowane Funkcje Admin
- Bulk actions (orders/leads/users).
- Eksport CSV/PDF.
- Globalne wyszukiwanie admin.
- Dashboard KPI (przychod, SLA, konwersja lead->order).
- Szacunek: 6-10 dni roboczych.
