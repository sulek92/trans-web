# PaletBroker Roadmap & Future Developments

## Phase 6: Advanced Features & Production Readiness (Completed)
- [x] **PWA Support**: Added `manifest.json` and basic PWA metadata for mobile.
- [x] **SEO Optimization**: Implemented `robots.ts` and `sitemap.ts` for search engines.
- [x] **Advanced Reporting**: Refactored CSV export in API to support UTF-8 BOM, escaping, and detailed fields.
- [x] **Admin Analytics**: Added "Carrier Distribution" chart to the dashboard.
- [x] **PDF Generation**: Implemented server-side generation of shipping labels (A6) and invoices (A4) using `pdfkit`.
- [x] **Client Communication**: Added a premium `ChatWidget` component to the client panel for real-time support simulation.

## Phase 7: Scale & Performance (Completed)
- [x] **Real-time Engine**: Implemented Socket.io for live notifications and status updates.
- [x] **Advanced Caching**: Implemented Redis caching for `pricing_rules` to reduce DB load.
- [x] **Centralized Infrastructure**: Created global Redis and Websocket modules in API.
- [x] **Observability**: Implemented Health Check endpoints and metrics for monitoring.
- [x] **Edge Optimization**: Implemented `CacheControlInterceptor` for CDN/Edge caching.

## Phase 8: Strategic Integrations & Bulk Operations (Completed)
- [x] **API Key System**: Programmatic access for ERP/WMS systems (B2B).
- [x] **Carrier Logic**: Implemented unified integration layer for DHL/DPD with Sandbox/Production support.
- [x] **Automated Labels**: Auto-generating shipping labels and tracking numbers after payment.
- [x] **Bulk Actions**: Added support for mass status updates and label generation in Admin.
- [x] **ERP Adapters**: Implemented foundational layer and File Upload API for Subiekt/Optima.
- [x] **Address Management**: Implemented `AddressBook` with bulk import support.

## Phase 9: Global Expansion & Enterprise (In Progress)
- [x] **Multi-currency**: Implemented support for PLN, EUR, USD, GBP with real-time conversion layer.
- [x] **Advanced Analytics**: Implemented user and admin shipping analytics (Revenue, Trends).
- [x] **Financial Automation**: Refactored PDF engine for bilingual, multi-currency invoices.
- [x] **Enterprise Identity**: Implemented SSO strategies (Azure AD, Google OAuth2).
- [x] **Invoice Corrections**: Automated flow for price adjustments and credit notes (UI Integrated).
- [x] **Advanced Audit Trail**: Implemented diff-based logging for critical entity changes (Pricing rules tracked).
- [x] **Admin UI Polish**: Implemented dedicated System Logs page and advanced dashboard widgets.
- [ ] **Real Carrier APIs**: Connecting to production DHL/DPD WebServices (Requires Credentials).
- [ ] **International Carriers**: Integration with UPS, FedEx, Kuehne+Nagel.
